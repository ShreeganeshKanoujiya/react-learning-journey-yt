## 💡 How to Run Projects

1. Clone the repository

```bash
git clone https://github.com/ShreeganeshKanoujiya/react-learning-journey-yt.git
```

2. Navigate to project folder

```bash
cd project-name
```

3. Install dependencies

```bash
npm install
```

4. Start development server

```bash
npm run dev
```
